# InboxIQ

**Every reply is a revenue decision.**

InboxIQ connects to any email inbox — Gmail or Outlook — and surfaces hidden revenue opportunities that have gone cold, been forgotten, or were never properly followed up on.

Built for B2B sales teams. Part of the [ReviveIQI](https://reviveiqi.com) suite.
